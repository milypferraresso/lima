# Exercícios de XML

## Descrição

Este repositório reúne os exercícios práticos de XML desenvolvidos na disciplina de Linguagens de Marcação.

As atividades consistiram na análise de documentos XML com erros de sintaxe, realizando as correções necessárias para que cada arquivo seguisse as regras da linguagem e apresentasse uma estrutura válida.

---

## O que foi desenvolvido

Durante a atividade foram realizadas as seguintes tarefas:

- Análise de documentos XML.
- Identificação de erros de sintaxe.
- Correção de tags, atributos e caracteres especiais.
- Organização dos arquivos em um repositório GitHub.

---

## Conteúdos Trabalhados

- Estrutura de documentos XML.
- Declaração XML.
- Elementos e atributos.
- Regras de sintaxe.
- Hierarquia entre elementos.
- Correção de documentos XML.

---

## Objetivo da Atividade

O principal objetivo foi compreender o funcionamento da linguagem XML e aplicar seus conceitos na prática, aprendendo a identificar e corrigir erros de estrutura para produzir documentos bem formados.
