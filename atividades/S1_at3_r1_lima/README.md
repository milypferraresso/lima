# Meu Perfil - Página Pessoal

## Sobre a atividade

Nesta atividade, criei uma página HTML para falar um pouco sobre mim, meus hobbies e o que espero para o meu futuro profissional.

A proposta foi praticar a utilização do HTML, principalmente das tags semânticas, deixando a página organizada e fácil de entender.

## Objetivo

O objetivo da atividade foi criar uma página simples utilizando apenas HTML, colocando em prática os conhecimentos aprendidos sobre:

- Estrutura do HTML;
- Tags semânticas;
- Organização do conteúdo;
- Acessibilidade;
- Boas práticas no desenvolvimento de páginas web.

## O que foi utilizado

Para desenvolver a página, utilizei:

- HTML5
- Visual Studio Code

## Como fiz a página

Comecei criando a estrutura básica do HTML e depois fui adicionando as partes que foram pedidas na atividade.

Usei a tag `<header>` para fazer o cabeçalho da página e colocar o título.

Depois, dentro do `<main>`, organizei as informações em diferentes `<section>`, separando os assuntos como "Sobre mim", "Hobbies" e "Meu futuro profissional".

Também utilizei:

- `<h1>` para o título principal;
- `<h2>` para os títulos das seções;
- `<p>` para os textos;
- `<footer>` para o rodapé da página.
